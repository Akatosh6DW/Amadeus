# Amadeus System：加入简单的自主生活

[English](README.en.md)

在 Windows 桌面上和 Amadeus 聊天。

## 加入简单的自主生活

这是相对 v1.1.1 的本次公开源码更新。自主生活默认关闭；要使用本次更新，请从仓库源码运行，现有安装包仍是 v1.1.1。QQ 代管、QQ 空间、出站语音、待办和提醒等已有能力继续保留。

本次更新让阅读、闲聊、整理想法和空间分享分别安排时间，并把你与她的 QQ 私聊接入共同日常。还增加了公开来源阅读、可选的 QQ 语音识别、按会话补回遗漏消息，以及分条回复、逐条打字等待、表情轮换和桌面粘贴图片。Bluesky、Bangumi、arXiv 和 RSS/Atom 的新增访问能力仅限公开阅读。

Amadeus System 是一个《命运石之门》同人项目。桌面上的 Live2D 角色以牧濑红莉栖为原型，能陪你聊天、记住你说过的事、帮你管理待办和提醒，可以用中文或日语开口说话，口型跟着声音动。

## 能做什么

- **聊天和记忆**：她会记住你的偏好和长期在做的事，换个会话也还记得。
- **待办和提醒**：在待办面板里添加，或者直接说“明天上午九点提醒我开会”；也可以让她过一会儿再读一段话给你听。提醒和延时任务需要保持程序运行。
- **提醒完成状态**：一次性纯提醒可在成功送达后自动移出未完成列表；需要你亲自做完的普通待办仍由你确认，重复任务继续保留下次安排。
- **周期任务**：例如“每周一上午九点，根据我当前研究兴趣推荐论文”。可以通过对话修改内容、暂停和恢复，也可以在待办编辑器设置“到点动作”和周期。后端运行时自动执行，结果保存后交给桌面显示；后端停止或电脑休眠期间不会准时执行，恢复后合并补跑一次。
- **语音和表情**：桌面朗读支持中文、日文，表情和动作跟着内容变化；QQ 的文字/语音、语言和语音比例可以另外设置。QQ 图库支持静态图片和 GIF 动图，保留原始图片发送。
- **看图和查资料**：桌面聊天框可直接粘贴图片。在你允许后，她可以看图片、截图和摄像头画面，读写文本文件，联网搜索并给出来源。
- **联网研究**：在浏览器设置中选择 DeepSeek 搜索、Bing 或 DuckDuckGo，并设置备用方式。查询可继续读取网页、PDF 文本、定位关键词和翻页；默认 quick / standard / deep / exhaustive 的工具调用上限为 12 / 32 / 64 / 160 次，研究时间上限为 60 / 120 / 240 / 600 秒，可在设置中调整。预算并非必须用满；网站拒绝访问、扫描 PDF 无文字等情况仍会如实报告。
- **QQ 代管**：按好友或群分别设置是否回复、触发方式、回复身份、人格、语音和间隔；支持按意思分条、模拟打字等待、图片/表情包、引用和历史消息。主人可以通过 QQ 控制已开放的工具，账号配置和各自上下文分开保存。
- **入站 QQ 语音**：准备好可选的本地语音识别环境和模型后，可以直接发送 QQ 语音；识别结果进入普通聊天流程，不改变出站语音设置。
- **登录后补回**：在具体好友或群的设置中开启“登录后补回遗漏消息”。默认关闭，从开启时开始记录；下次登录或重连补看最近最多 90 条消息并集中回复，保留暂停、审核和群触发设置。
- **人格与表达**：本地默认使用红莉栖人格；QQ 对象可选红莉栖、孙吧或抗吧独立人格。论坛模式只读取本机已安装的语料；孙吧/抗吧语料不随公开源码或 Release 分发，未安装时仍可选人格但不会加载论坛示例。
- **主动互动与等待**：可以让她暂时安静等待；Live2D 的月牙标记表示等待状态，你主动发消息仍可得到回应。
- **自主生活（简单实验性功能）**：按自己的兴趣定时阅读授权目录、公开网页、Bluesky 动态、Bangumi 条目、arXiv 摘要和 RSS/Atom，保留独立的阅读日记与待探索问题；以阅读、聊天、整理想法和考虑空间分享四个独立节律运行，可生成 QQ 空间草稿，或按你设置的账号和发布额度自动发布。默认关闭，尚未包含在 v1.1.1 安装包中。
- **外观**：桌面悬浮和视频通话两种布局，两套服装，背景可以换成自己的图片。

## 安装

1. [下载安装器 AMADEUS-v1.1.1-setup.zip](https://github.com/Akatosh6DW/Amadeus/releases/download/v1.1.1/AMADEUS-v1.1.1-setup.zip)（约 17 KB；完整程序由安装器下载）。
2. 解压后双击 `install-release.cmd`，安装器会自动下载程序、运行环境和声音资源，默认装在 `%USERPROFILE%\Apps\Amadeus`。
3. 运行 `AMADEUS.exe`，在“设置 → API”里填入你的 API Key。

默认使用 DeepSeek（Endpoint `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`）。也支持配置其他兼容 OpenAI 接口的服务；看图功能需要模型支持图片输入。

v1.1.1 整合 QQ 代管与独立人格，以及提醒、记忆、历史和语音修复，并修正自动更新的进程交接。旧版用户请先用本版安装器升级；以后可在“设置 → 更新”检查并安装新版，继续使用原有配置和聊天记录。详见 [发行说明](https://github.com/Akatosh6DW/Amadeus/releases/tag/v1.1.1)。

## 从源码运行

要使用“加入简单的自主生活”及其他本次源码更新，请从当前仓库运行；现有可下载安装包仍为 v1.1.1，不包含这些更新。真实任务是否成功仍以工具回执和平台结果为准。

```powershell
git clone --depth 1 https://github.com/Akatosh6DW/Amadeus.git
cd Amadeus
.\start.cmd
```

第一次运行会自动安装桌面和出站语音环境，并下载约 614 MB 的已发布 voice/context 资源、GPT-SoVITS/Python/PyTorch 等数 GB 依赖；首次仍需你在“设置 → API”填入自己的 API Key。入站 QQ 语音的本地 ASR 是可选能力，源码语音环境包含 faster-whisper，但 `start.cmd` 不会下载 QQ 识别所用的 small 模型，需要另行准备本地模型，见 [QQ 配置与使用说明](integrations/qq/README.md#接收-qq-语音本地-asr)。下载中断或失败时保留项目内缓存，重新运行同一个 `start.cmd` 即可继续。

孙吧/抗吧语料属于可选本地数据，不随公开源码或 Release 分发；QQ 配置、人格选择、入站语音和本地语料边界见 [QQ 配置与使用说明](integrations/qq/README.md)。

## 环境要求

### QQ 快速配置

QQ 功能默认关闭。源码首次安装会下载固定版本的 NapCat 接入组件；发布构建会内置同一组件。**不包含也不下载 QQ 客户端**，请先自行安装 QQ NT。

1. 打开 **设置 → QQ → 账号与登录**，点击 **连接本机 QQ**。已有普通 QQ 在运行时先自行退出；找不到客户端时展开「手动指定 QQ 路径」。
2. 用手机 QQ 扫码，核对页面显示的登录账号；按页面提示点击 **改用已登录账号** 或 **连接这个账号**。登录成功不会自动开始回复。
3. 在 **主人权限** 填写你本人的 QQ 号；这是远程控制者，与助手登录的账号分开。
4. 在 **回复谁 → 添加好友或群** 选择对象并「加入列表」。点每个对象旁的 **设置**，进入独立页面设置身份、人格、群触发方式、文字/语音和间隔。
5. 在 **回复设置** 选择「自动回复，直接发送」或「先生成草稿，我确认后才发送」，点击 **保存设置**，再点击顶部 **▶** 开始。**⏸** 暂停回复；「退出 QQ 后台」停止连接。

地址、密钥和对象设置自动保存在本机。**账号与登录** 可新增账号或切换已保存配置；切换配置后保持暂停，还需登录相同 QQ 号。每个账号的联系人、回复要求和聊天上下文独立，不会因为填写新号码就完成 QQ 登录。

已在这台电脑登录过的账号可使用 NapCat 的自动登录目标复用本机凭据，详见 [记住账号与自动登录](integrations/qq/README.md#记住账号与自动登录)。这属于本机设置；显式重新登录/换号会清空目标，凭据失效时仍可能需要扫码。

完整步骤、按钮说明、主人远程控制、新账号验收和排错见 [QQ 配置与使用说明](integrations/qq/README.md)。NapCat 官方压缩包约 34.2 MiB，展开约 109.3 MiB；复用 Amadeus 运行环境，不需要安装 AstrBot。v1.1.1 安装包已内置 QQ 接入组件，首次使用仍需你选择账号并扫码登录。

### 运行条件

- Windows 10/11 x64，建议 16 GB 内存。
- Release 安装约需 30 GB 空间，源码运行约需 40 GB。
- 有 NVIDIA 显卡时语音合成更快，没有也可以用 CPU 运行。

## 数据和隐私

聊天、个人记忆、工程偏好、待办和设置保存在本机；QQ 配置不会作为个人事实写进长期记忆。对话、识图、自动摘要和表情判断等功能会将所需内容发送到你配置的模型服务；联网工具会访问相应网站。

## 使用自主生活

自主生活默认关闭。想让她偶尔通过 QQ 来找你闲聊：先在 QQ 页保存代理账号和主人 QQ，再在自主生活中勾选“允许主动 QQ 聊天”、选择主人并保存。只有一个主人时会自动选中。聊天有独立的考虑时间，不会因为一直阅读而被挤掉；是否开口、聊什么和说多少仍由她决定，没有固定开场。桌面对话、生活经历、空间动态和你与她的 QQ 主人私聊可进入同一段日常上下文；消息按意思分成完整的小段。QQ 自动发送/待审核/暂停设置继续生效，聊天记录会显示真实发送状态。要持续运行，还需开启自主生活并保持后端和 QQ 连接在线。

QQ 空间与自主生活共享兴趣、近期经历和实际发布回执：生活中的发现可以成为动态，独立空间浏览读到的内容也可以成为下一次闲聊的话题。原有空间自动浏览设置继续有效；消息和动态不会仅凭模型说“完成”就记作已经发送。

自主生活将 QQ 阅读分享固定为文字，方便阅读和引用；普通聊天的语音设置保持不变。已发送语音若存在同会话的文本底稿与平台回执，可在后续引用中恢复原文；这不会改写 QQ 中原有的语音气泡。定时任务也会保留有效正文，可选语音失败时仍可文字交付，真实执行失败与未知发送继续单独报告。

桌面对话和你与她的 QQ 私聊也会进入同一段日常生活；QQ 以所选账号与主人身份匹配，其他联系人、群聊不计入。她可以留下持续兴趣与没聊完的话题，结合后续交流决定继续或放下；“还惦记的事”中可以暂停、继续、结束。重启保留记录，时间到了只会重新考虑，不强制开口。

人格与通用表达设置在桌面、自主生活和主人的默认 QQ 人格之间共用。她自己的活动和主动话题以论文、科学、互联网、网络文化与亚文化等能够实际接触的内容为主，区分读到、想到和亲身做过，不虚构线下生活经历。你谈现实生活时，她仍可自然接话。

从源码运行时打开 **设置 → 自主生活**，填写兴趣、非敏感阅读目录和起始网页或 RSS/Atom 地址，然后保存。可以先点“试运行一次”，查看实际阅读记录、兴趣笔记和动态草稿；开启后，程序会在活动时段自动运行，关闭设置页不影响后台。

起始来源旁的“添加常用来源”可加入 Bluesky、Bangumi、arXiv 天文订阅和 Python 更新；也可自行填写公开地址。新增来源会保留已有输入，点击“保存设置”后生效。公开阅读沿用“权限 → 联网搜索”与自主生活的“允许读取公开来源”，不需要登录这些平台，也不会替你打开权限；这些平台在本次更新中仍只读，不支持登录、关注、评论或发帖。

普通聊天也可以请她搜索 Bluesky 帖子、查看某个公开账号或帖子讨论、查 Bangumi 作品、寻找 arXiv 论文或阅读订阅。Bluesky 返回帖子文字，Bangumi 返回条目介绍与元数据，arXiv 返回题目、作者、摘要和原文链接，RSS/Atom 返回订阅实际提供的内容；读过摘要不等于读过论文全文，条目介绍也不等于观看作品。

频率只需调“总体活跃程度”。标准 100% 时，阅读探索约每 2 小时、考虑找你聊天约每 3 小时、整理想法约每 6 小时、考虑空间分享约每 12 小时；200% 将这些间隔减半，50% 将间隔加倍。四项分别计时并保存，下次时间在页面中可见，重启不会清空。刚开启时会错开安排：阅读先开始，聊天约 15 分钟后首次考虑，整理约 1 小时后，空间约 2 小时后（同样随总体活跃程度缩放）。这些是考虑机会，不是固定发言任务；没有想说的可以安静结束。发过主动私聊后，至少再等一个聊天间隔；活动时段、原有账号权限、审核方式、每日空间发布上限继续生效。

旧版所有活动共用的每日次数不再挤占聊天机会；旧配置文件仍可读取。手动试运行不推迟四项自动安排，实际产生的聊天和发布仍计入原有发送保护。每次活动继续使用有界的工具步数和时间，多个到期活动依次执行，停机期间的次数不会成批补发。

阅读目录必须由你明确选择，当前支持其中的 UTF-8 文本；被读取的内容会发送到所选模型，请不要放入密码、私信或其他敏感材料。公开网页地址只是探索起点，她可以继续访问其他公开来源。文件和网页仍受全局读取权限约束。日记和兴趣笔记保存在本机独立数据库，不自动写入你的个人事实记忆；在桌面对话中可让她查看生活日记，聊聊最近读了什么。

发布默认只存草稿，可编辑后发送或丢弃。要自动发 QQ 空间动态，可点击“使用当前代理账号”，或将账号留空，在保存/试运行时绑定 QQ 页当前配置的代理账号；也可手动填写完整 QQ 号。绑定会保存，之后切换代理账号不会自动更换生活账号或已有草稿的账号。选择可见范围与每日额度，再启用“自动发布”；现有 QQ 连接、账号范围和空间发布权限仍须有效。这里的空间草稿设置独立于 QQ 私聊/群聊的审核模式。保留现有 QQ 空间发布适配器，尚未接入其他平台的登录浏览器发帖。

“立即停止”会关闭后续唤醒并取消尚未执行的操作；已发出的网络请求无法撤回。结果未知的发布会保留回执供核对，不会自动重发。此功能依据结构化工具调用执行，不靠关键词或正则猜测用户授权。首次真实账号发布前，建议先用“仅生成草稿”核对内容和范围。

表情系列可在“设置 → 表情”控制前端回复，在“QQ → 对象旁的设置 → 表情包系列与比例”单独控制好友或群。勾选系列后拖动滑块，例如咒术回战 40%、奶蛙 20%，其余约 40% 不主动配图。总和不超过 100%；比例决定尝试配图的频率，模型仍会跳过不贴切的图，明确索要图片则优先完成请求。QQ 对话关闭自定义后继承 QQ 默认配置；自定义但不选系列表示不主动配图。

## 已知问题

设置保存、待办创建和 QQ 实际发送是不同的结果。QQ 自动发送成功默认不额外刷成功气泡；失败或发送状态未知时会说明，详细结果可查看 QQ 动态。提醒需要后端保持运行；程序退出、电脑休眠或 QQ 离线时不能保证按时送达。

当前版本已移除按用户措辞猜授权、重复登记任务等误拦路径；用户设置的权限、账号/收件人范围、暂停/审核模式及防重复发送仍有效。完整缺陷与实际验收范围由本地 `BUGS.md` 维护，不能把一次测试通过理解为所有外部平台永不失败。

使用中遇到错误或有功能建议，欢迎提 Issue，或发送邮件至 [akatoshll6dw@gmail.com](mailto:akatoshll6dw@gmail.com)。反馈错误时，请尽量附上软件版本、操作步骤和错误截图，方便定位问题。
