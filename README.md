# Amadeus System

[English](README.en.md)

在 Windows 桌面上和 Amadeus 聊天。

Amadeus System 是一个《命运石之门》同人项目。桌面上的 Live2D 角色以牧濑红莉栖为原型，能陪你聊天、记住你说过的事、帮你管理待办和提醒，可以用中文或日语开口说话，口型跟着声音动。

## 能做什么

- **聊天和记忆**：她会记住你的偏好和长期在做的事，换个会话也还记得。
- **待办和提醒**：在待办面板里添加，或者直接说“明天上午九点提醒我开会”；也可以让她过一会儿再读一段话给你听。提醒和延时任务需要保持程序运行。
- **提醒完成状态**：一次性纯提醒可在成功送达后自动移出未完成列表；需要你亲自做完的普通待办仍由你确认，重复任务继续保留下次安排。
- **周期任务**：例如“每周一上午九点，根据我当前研究兴趣推荐论文”。可以通过对话修改内容、暂停和恢复，也可以在待办编辑器设置“到点动作”和周期。后端运行时自动执行，结果保存后交给桌面显示；后端停止或电脑休眠期间不会准时执行，恢复后合并补跑一次。
- **语音和表情**：桌面朗读支持中文、日文，表情和动作跟着内容变化；QQ 的文字/语音、语言和语音比例可以另外设置。
- **看图和查资料**：在你允许后，她可以看图片、截图和摄像头画面，读写文本文件，联网搜索并给出来源。
- **联网研究**：在浏览器设置中选择 DeepSeek 搜索、Bing 或 DuckDuckGo，并设置备用方式。查询可继续读取网页、PDF 文本、定位关键词和翻页；默认 quick / standard / deep / exhaustive 的工具调用上限为 12 / 32 / 64 / 160 次，研究时间上限为 60 / 120 / 240 / 600 秒，可在设置中调整。预算并非必须用满；网站拒绝访问、扫描 PDF 无文字等情况仍会如实报告。
- **QQ 代管**：按好友或群分别设置是否回复、触发方式、回复身份、人格、语音和间隔；支持短句分条、图片/表情包、引用和历史消息。主人可以通过 QQ 控制已开放的工具，账号配置和各自上下文分开保存。
- **人格与表达**：本地默认使用红莉栖人格；QQ 对象可选红莉栖、孙吧或抗吧独立人格。论坛模式只读取本机已安装的语料；孙吧/抗吧语料不随公开源码或 Release 分发，未安装时仍可选人格但不会加载论坛示例。
- **主动互动与等待**：可以让她暂时安静等待；Live2D 的月牙标记表示等待状态，你主动发消息仍可得到回应。
- **外观**：桌面悬浮和视频通话两种布局，两套服装，背景可以换成自己的图片。

## 安装

1. 从 [v1.1.0 Release](https://github.com/Akatosh6DW/Amadeus/releases/tag/v1.1.0) 下载 `AMADEUS-v1.1.0-setup.zip`。
2. 解压后双击 `install-release.cmd`，安装器会自动下载程序、运行环境和声音资源，默认装在 `%USERPROFILE%\Apps\Amadeus`。
3. 运行 `AMADEUS.exe`，在“设置 → API”里填入你的 API Key。

默认使用 DeepSeek（Endpoint `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`）。也支持配置其他兼容 OpenAI 接口的服务；看图功能需要模型支持图片输入。

v1.1.0 加入 QQ 代管与独立人格，并修复提醒完成状态、长期偏好保存、历史恢复和语音交付。v1.0.2 用户可在“设置 → 更新”检查并安装新版，继续使用原有配置和聊天记录；更早版本请使用安装器。详见 [发行说明](https://github.com/Akatosh6DW/Amadeus/releases/tag/v1.1.0)。

## 从源码运行

```powershell
git clone --depth 1 https://github.com/Akatosh6DW/Amadeus.git
cd Amadeus
.\start.cmd
```

第一次运行会自动安装桌面和语音环境，并下载约 614 MB 的已发布 voice/context 资源、GPT-SoVITS/Python/PyTorch 等数 GB 依赖；首次仍需你在“设置 → API”填入自己的 API Key。下载中断或失败时保留项目内缓存，重新运行同一个 `start.cmd` 即可继续。

孙吧/抗吧语料属于可选本地数据，不随公开源码或 Release 分发；QQ 配置、人格选择和本地语料边界见 [QQ 配置与使用说明](integrations/qq/README.md)。

## 环境要求

### QQ 快速配置

QQ 功能默认关闭。源码首次安装会下载固定版本的 NapCat 接入组件；发布构建会内置同一组件。**不包含也不下载 QQ 客户端**，请先自行安装 QQ NT。

1. 打开 **设置 → QQ → 账号与登录**，点击 **连接本机 QQ**。已有普通 QQ 在运行时先自行退出；找不到客户端时展开「手动指定 QQ 路径」。
2. 用手机 QQ 扫码，核对页面显示的登录账号；按页面提示点击 **改用已登录账号** 或 **连接这个账号**。登录成功不会自动开始回复。
3. 在 **主人权限** 填写你本人的 QQ 号；这是远程控制者，与助手登录的账号分开。
4. 在 **回复谁 → 添加好友或群** 选择对象并「加入列表」。点每个对象旁的 **设置**，进入独立页面设置身份、人格、群触发方式、文字/语音和间隔。
5. 在 **回复设置** 选择「自动回复，直接发送」或「先生成草稿，我确认后才发送」，点击 **保存设置**，再点击顶部 **▶** 开始。**⏸** 暂停回复；「退出 QQ 后台」停止连接。

地址、密钥和对象设置自动保存在本机。**账号与登录** 可新增账号或切换已保存配置；切换配置后保持暂停，还需登录相同 QQ 号。每个账号的联系人、回复要求和聊天上下文独立，不会因为填写新号码就完成 QQ 登录。

完整步骤、按钮说明、主人远程控制、新账号验收和排错见 [QQ 配置与使用说明](integrations/qq/README.md)。NapCat 官方压缩包约 34.2 MiB，展开约 109.3 MiB；复用 Amadeus 运行环境，不需要安装 AstrBot。v1.1.0 安装包已内置 QQ 接入组件，首次使用仍需你选择账号并扫码登录。

### 运行条件

- Windows 10/11 x64，建议 16 GB 内存。
- Release 安装约需 30 GB 空间，源码运行约需 40 GB。
- 有 NVIDIA 显卡时语音合成更快，没有也可以用 CPU 运行。

## 数据和隐私

聊天、个人记忆、工程偏好、待办和设置保存在本机；QQ 配置不会作为个人事实写进长期记忆。对话、识图、自动摘要和表情判断等功能会将所需内容发送到你配置的模型服务；联网工具会访问相应网站。

## 已知问题

设置保存、待办创建和 QQ 实际发送是不同的结果。QQ 自动发送成功默认不额外刷成功气泡；失败或发送状态未知时会说明，详细结果可查看 QQ 动态。提醒需要后端保持运行；程序退出、电脑休眠或 QQ 离线时不能保证按时送达。

当前版本已移除按用户措辞猜授权、重复登记任务等误拦路径；用户设置的权限、账号/收件人范围、暂停/审核模式及防重复发送仍有效。完整缺陷与实际验收范围由本地 `BUGS.md` 维护，不能把一次测试通过理解为所有外部平台永不失败。
